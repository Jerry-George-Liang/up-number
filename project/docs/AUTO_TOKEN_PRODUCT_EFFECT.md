# Chrome 自动获取后台 Token：非技术版效果说明

- 状态：已取消，未实施；改回账号密码登录
- 日期：2026-08-11
- 目标页面：`https://coding.tu-zi.com/admin/dashboard`

> 2026-08-11 用户决定不再开发 Chrome 自动获取 Token。后续认证效果以 `docs/ACCOUNT_PASSWORD_LOGIN_PRODUCT_EFFECT.md` 为准。

## 1. 完成后的效果

设置页不再要求用户复制并粘贴后台 Token。用户在当前 Chrome 中保持后台 Dashboard 已登录，点击“从当前 Chrome 自动连接”后，工具自动取得可长期恢复的后台登录凭据并完成连接。

连接过程中和连接成功后都不显示 Token 内容。连接成功后仍只显示“后台会话已连接”、当前后台用户摘要和 `Refresh Token` 模式。以后重新启动工具时，已保存且仍有效的会话继续自动恢复，不需要再次从 Chrome 获取。

设置页保留“手动粘贴 Token”作为折叠的备用方式，供扩展不可用或后台页面状态异常时使用；它不再是默认操作。

## 2. 首次准备

1. 用户安装并启用本工具配套的 Chrome 扩展。
2. 用户在同一个 Chrome Profile 中打开后台 Dashboard，并按后台正常流程完成登录。
3. 用户使用本次启动生成的一次性本地确认链接进入工具。

本地启动确认与后台 Token 是两件不同的事情。未完成一次性本地确认时，页面继续显示“需要本地启动会话”，不会尝试从 Chrome 获取后台 Token。

## 3. 主要操作流程

1. 用户进入设置页。
2. 页面检查配套扩展是否可用，并显示当前准备状态。
3. 用户点击“从当前 Chrome 自动连接”。
4. 扩展只查找当前 Chrome Profile 中已登录的目标后台页面。
5. 找到有效登录状态后，工具自动完成后台连接并保存会话。
6. 页面切换为“后台会话已连接”，任务页加载代理、订阅、供应商和分组选项。

“自动获取”表示不需要复制、查看或粘贴 Token，但仍需要一次明确的用户点击。设置页打开时不会在后台静默读取登录凭据。

## 4. 异常状态

- 未安装或未启用扩展：显示“未检测到 Chrome 扩展”，提供安装或重新检测入口，不反复弹窗。
- 未打开目标后台页面：显示“未找到后台 Dashboard”，提供“打开后台 Dashboard”按钮。
- 后台页面未登录：提示用户在已打开的官方页面完成登录，然后返回设置页重试；工具不接收后台账号、密码、验证码或安全验证信息。
- 登录状态中没有可用凭据：显示“当前后台登录状态不可用，请重新登录”，不保存空值或旧值。
- 自动连接失败：显示不含 Token 的原因，允许重试或展开手动备用方式。
- 已经连接：不再显示自动获取按钮，只显示连接状态和退出按钮。
- 会话以后失效：清理本机失效会话并回到未连接状态，允许再次从 Chrome 获取。

## 5. 权限和隐私表现

- 扩展只服务于目标后台页面和本机工具，不读取其他网站。
- 不读取或展示 Chrome 保存的密码、Cookie、浏览历史、书签、下载或表单内容。
- 不把 Token 复制到剪贴板，不显示在页面、通知、错误信息、任务记录或截图中。
- 不把后台凭据上传到其他服务，不在多个 Chrome Profile 之间同步。
- 不绕过后台登录、验证码、CAPTCHA、MFA、权限或合规确认。
- 用户在设置页点击“退出”后，工具清理本机保存的后台会话；Chrome 中的后台登录状态保持不变。

## 6. 本次包含

- 配套 Chrome 扩展及一次性安装说明。
- 设置页扩展状态、自动连接、重试、打开 Dashboard 和手动备用入口。
- 从当前 Chrome Profile 的已登录 Dashboard 获取 Refresh Token 并连接后台。
- 成功后保存会话、重启恢复和退出清理。
- 对未安装、未登录、Token 缺失、Token 失效和连接失败的明确提示。

## 7. 本次不包含

- 在设置页打开时无操作地静默提取 Token。
- 读取其他 Chrome Profile、其他浏览器或无关网站的登录状态。
- 自动填写或保存后台账号、密码、TOTP、验证码或安全问题。
- 自动完成 CAPTCHA、MFA、合规确认或其他后台安全挑战。
- 修改 `coding.tu-zi.com` 网站或服务端。
- 自动发布 Chrome Web Store；本次先提供本机安装包和安装说明。

## 8. 验收标准

1. 已安装扩展、Dashboard 已登录且完成本地启动确认时，点击一次即可连接后台，不需要查看、复制或粘贴 Token。
2. 自动连接成功后，页面和日志都不出现 Token，任务页能够正常加载后台选项。
3. 未安装扩展、未打开 Dashboard、未登录、Token 缺失或 Token 失效时，页面给出对应提示且不会误报连接成功。
4. 扩展不会因打开设置页而静默提取；只有点击“从当前 Chrome 自动连接”后才执行本次获取。
5. 手动 Token 登录仍可作为折叠备用方式使用。
6. 工具重启后优先恢复已经保存的有效会话，不重复从 Chrome 获取。
7. 退出工具会话不退出 Chrome 中的后台 Dashboard，也不影响 Chrome 中的其他网站。
