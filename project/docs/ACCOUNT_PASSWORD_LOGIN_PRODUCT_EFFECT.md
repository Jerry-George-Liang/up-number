# 后台账号密码登录：非技术版效果说明

- 状态：已实施，合成页面回归通过，真实有效账号登录待用户验收
- 编写日期：2026-08-11
- 确认日期：2026-08-12
- 目标后台：`https://coding.tu-zi.com/admin/`

## 1. 完成后的效果

设置页不再要求用户获取、复制或粘贴 Token，也不需要安装 Chrome 扩展。未连接后台时，用户输入后台登录邮箱和密码，点击“登录后台”即可建立本地工具会话。

根据当前后台登录页面的实际字段，“账号”指后台登录邮箱。登录成功后，设置页只显示“后台会话已连接”和当前用户摘要，不显示后台返回的 Token。

登录密码只用于本次登录请求。无论成功或失败，页面都会立即清空密码；工具不长期保存密码。后台签发的可续期会话保存在本机系统凭据存储中，以便工具重启后自动恢复，不要求用户重复登录。

## 2. 登录流程

1. 用户通过本次启动的一次性本地确认链接进入工具。
2. 用户打开设置页，输入后台登录邮箱和密码。
3. 用户点击“登录后台”，工具调用后台现有登录能力。
4. 如果后台不要求二次验证，登录成功后直接显示已连接状态并加载任务选项。
5. 如果后台要求 TOTP，设置页进入二次验证步骤，只显示一个验证码输入；提交正确验证码后完成登录。
6. 登录成功后，任务页加载代理、订阅、供应商和分组选项。

TOTP 输入只在后台明确要求时出现，不作为首次登录的固定第三个输入。密码和 TOTP 提交后都会立即清空，不会出现在任务记录、日志或页面结果中。

## 3. 后续使用与退出

- 工具重启后优先恢复本机已经保存且仍有效的后台会话。
- 会话续期成功时继续使用，不要求重新输入账号密码。
- 会话已经失效或被后台撤销时，清理失效的本机会话并重新显示登录表单。
- 用户点击“退出”后，工具退出后台会话并清理本机保存的会话凭据。
- 退出本地工具不会修改浏览器中 `coding.tu-zi.com` 的登录状态。

## 4. 异常状态

- 账号或密码为空：不发送请求，并在对应输入处提示。
- 账号或密码错误：显示“后台账号或密码错误”，清空密码并允许重试。
- 需要 TOTP：进入二次验证步骤，不误报为登录失败。
- TOTP 错误或过期：显示对应提示，清空验证码并允许重试或返回账号密码登录。
- 网络不可用：保留账号邮箱、清空密码，并提示稍后重试。
- 账号没有所需管理权限：明确提示权限不足，不当作密码错误。
- 后台要求合规确认或其他人工操作：引导用户先到后台完成，不自动绕过。
- 已经连接：隐藏登录表单，只显示连接状态和退出按钮。

## 5. 权限与隐私表现

- 后台地址固定，设置页不能输入或更换后台地址。
- 密码、TOTP 和后台 Token 都不显示在连接结果、错误信息、日志、截图或任务历史中。
- 密码和 TOTP 不写入浏览器存储、数据库或本机长期凭据存储。
- 本机长期保存的只有后台签发的可续期会话，并由系统凭据存储保护。
- 工具不读取 Chrome Cookie、浏览历史、密码管理器或其他网站信息。
- 工具不绕过后台登录、TOTP、CAPTCHA、MFA、权限或合规确认。

## 6. 本次包含

- 设置页后台登录邮箱和密码表单。
- 后台要求时出现的 TOTP 二次验证步骤。
- 登录成功后的会话保存、续期、重启恢复和退出清理。
- 错误账号密码、TOTP、网络、权限和合规状态提示。
- 桌面端、移动端和真实账号登录的页面测试。

## 7. 本次不包含

- Chrome 扩展或从当前 Chrome 自动读取 Token。
- 手动输入 Refresh Token 或 Access Token。
- 保存后台账号密码或自动重放密码登录。
- 自动填写、绕过或代替用户完成后台 CAPTCHA、其他 MFA 或合规确认。
- 修改 `coding.tu-zi.com` 页面、服务端、账号或权限配置。
- 改变任务页已经确认的两个自由输入和自动创建 OpenAI OAuth 账号流程。

## 8. 验收标准

1. 未连接时，设置页只要求后台登录邮箱和密码；TOTP 仅在后台要求时出现。
2. 正确账号密码可以登录；需要 TOTP 时，正确验证码可以继续完成登录。
3. 登录成功后能加载任务页的后台选项，页面和日志不出现任何后台 Token。
4. 密码和 TOTP 在提交成功或失败后立即从页面清空，重启工具也不能恢复这些输入。
5. 工具重启后可以恢复仍有效的后台会话，不需要重新输入账号密码。
6. 错误账号密码、错误 TOTP、网络错误、权限不足和合规要求均有可区分的页面结果。
7. Chrome 扩展、自动取 Token 和手动 Token 输入不出现在最终界面中。
8. 必须完成桌面端、移动端和真实登录流程的页面测试；页面测试未通过时不视为完成。
9. 任务页仍只有账号邮箱和邮箱取件信息两个自由输入，其他配置继续只能选择。
